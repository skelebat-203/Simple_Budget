# Accessibility pass — v0.7

Run 2026-11-27 on the production build at v0.7.67 plus the fixes made in this pass (`npm run build` + `vite preview`, production CSP), headless Chromium (chrome-headless-shell), Lighthouse 13.5.0 accessibility category driven by puppeteer-core (snapshot mode). The v0.7 UI/UX review (step 16) was passed by the human first. Earlier passes: `a11y-v0.3.md` to `a11y-v0.6.md`.

## Result

One finding fixed (A1). Every state scores 100 at 1280, 375 and 320px (72 snapshots). The release gate is 90. **The screen reader test and keyboard walkthrough by the human are still to do** (Release checklist: a failure there is a hard stop).

- **A1** `src/components/MiscBreakdown.tsx`: `aria-label` is now `Save for future: {description}`. It starts with the visible text, stays unique in the table (the table-control check in `test:dialogs` passes) and is still described by its row header. Re-run: the audit is gone in every state.
- **Popup test** `tests/dialogs/run.mjs`: the heading is required only when `updates.json` lists known issues.

## Scripted checks (pass)

- **Reflow**: no sideways page scroll in any state at 320, 375 and 1280px.
- **Live region**: never more than one in any state; one visible `h1` in each state; title "Simple Budget"; `lang="en"`; one `main`; no unnamed `nav`, `section` or region; every table named; no image or SVG without alt or `aria-hidden`; heading levels do not skip.
- **Duplicate ids**: none in any state (v0.6 A5 stays fixed).
- **Focus**: a 45-press Tab walk in the wizard (steps 1 and 2), Budget setup, Day Update, Update row, highlight, Backup and the update popup: focus never leaves the top dialog, every stop shows a focus ring, none lands off screen, never on the body.
- **Target size** (WCAG 2.5.8): the only controls under 24px are checkboxes inside a 44×44px label (`.hit`, the `check` label) and the visually hidden radios of the wizard choice (their labels are the target); the scripted flags on them are not findings.
- **Text spacing** (WCAG 1.4.12): with line height 1.5, letter spacing 0.12em, word spacing 0.16em and paragraph spacing 2em applied, the wizard, Add purchase, Budget Week, the highlight dialog and Backup show no clipped text and no sideways page scroll at 1280 and 375px.
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` in `src/App.css` replaces the reward animations with a fade; rewards can be switched off in Budget setup.
- **Console and CSP**: no console error or warning and no `securitypolicyviolation` in any run (72 snapshots).
- **Dialog focus** (`test:dialogs`, 127 checks): focus moves into each dialog on open, Tab and Shift+Tab stay inside, Escape closes it and focus returns to the opener, including the info notes, the Update dialog and stacked dialogs.

## Not run in this pass

Forced colors and the sticky Save and Import footers at zoom (CLAUDE.md overrides). 200% and 400% zoom are covered by the 640px and 320px reflow checks. Google's own sign-in window and file Picker (third-party content) were not tested; the app's pages around them were.
