# Roadmap

Source of truth for versioning (see `versioning.md`). Current version: **v0.0.0**.

## v0.1 — Web PWA foundation
- Project scaffold (React + TS, Vite)
- Plain CSS tokens, in-house UI components
- IndexedDB storage + repository layer
- Add flow (dropdown search, date picker, amount, save, reward)

## v0.2 — Edit/Delete + Categories
- Edit flow (matching items, new values)
- Delete flow
- Categories CRUD
- Search/filter dropdown

## v0.3 — Budget views + rewards/settings
- Budget screen (Day/Week/Month/Year/Historic; Table/Chart)
- Rewards animation + settings toggle
- Notifications toggle (daily reminder)

## v0.4 — Sync
- Shared-account storage adapter (vendor-agnostic)
- OnlyOffice adapter + seed data import
- Sync-on-open (pull then push), conflict resolution

## v0.5 — Distribution + polish
- PWA install instructions (web, Android, GrapheneOS)
- Accessibility pass
- Offline robustness

## Post v1.0
- Receipt photo capture
- Capacitor APK build (if native notifications needed)
