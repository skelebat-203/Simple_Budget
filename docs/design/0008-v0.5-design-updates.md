# 0008 — v0.5 design updates

Human decisions of 2026-11-03 from the v0.4 review. Where this doc and `0007`
differ, this doc wins (each conflict is named below).

## 1. Table expanders

- Every expand/collapse control in every table (Budget setup; Budget Day, Week,
  Month, Annual) is a real `<button>` with `aria-expanded`, reachable by Tab.
- The button holds the icon and the row name: `▸ Expenses` / `▾ Expenses`. The
  icon is decorative (`aria-hidden`); the name is the button's text.

## 2. Budget setup keyboard

- Remove the table's own keyboard shortcuts (arrow keys, Home/End, Enter/F2 to
  edit, Escape back to the cell). Every field and button inside the table is a
  normal Tab stop.
- Keep `role="treegrid"` and `aria-level` / `aria-expanded` on rows.
- Screen reader table navigation (e.g. NVDA/JAWS table keys, VoiceOver table
  commands) must keep working; the accessibility pass tests it.
- Note for the build: the ARIA treegrid pattern expects author-provided arrow-key
  navigation, and some screen readers switch to focus mode inside it. If testing
  shows table keys stop working, bring it back to the human before changing the role.
- **Supersedes** the Budget setup part of the `0007` §10 keyboard model. The Budget
  tables (Day, Week, Month, Annual) keep it.

## 3. Due dates and recurrence

### 3.1 Placement in the tables

- An estimate with a recurrence **and** a due date is not spread across the
  range. Its full amount goes on the column holding the expected payment day
  (Week day, Month week, Annual month), and in that period's total.
- An estimate without a due date is spread as today (v0.4 scaling).

### 3.2 Due date field by recurrence (Budget setup)

| Recurrence | Due date control |
| --- | --- |
| Daily | None |
| Weekly, Every 2 weeks | Dropdown of weekdays |
| Bi-monthly (twice a month) | Two dropdowns: **1st payment** (1–15) and **2nd payment** (16–27, Last) |
| Monthly | Dropdown: 1–27, Last |
| Quarterly, Annual | Full date picker (date of the next payment) |

- "Last" means the last day of the month.
- Changing the recurrence clears a due date that no longer fits.

## 4. Week, Month and Annual column borders

- A solid border between each time period (day, week or month), including before
  Total. No border between a period's Est. and Act. columns.

## 5. Date navigation

- Previous and Next use left and right chevron icons; their accessible names
  stay "Previous {unit}" and "Next {unit}".
- The range-title button opens the browser's calendar directly, not a popover
  holding a date field. **Supersedes** the v0.4 popover (this restates `0007`
  §9.5: "opens the same date picker the Date field uses").
