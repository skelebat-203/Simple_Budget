# 0009 — v0.6 design updates

Human requests of 2026-11-04 from the v0.5 review. **Not final**: the wizard and the
highlight each have a prototype to review first (`0010-onboarding-wizard-prototype.html`,
`0011-highlight-prototype.html`); this doc is not authoritative for those two until the
human settles them. Where it differs from `0008` §8 (onboarding), the wizard replaces the
single-dialog questionnaire once decided.

## 1. Onboarding wizard

A dialog wizard with a progress bar (step X of 3).

1. How often do you get paid? (same options as `0008` §8)
2. Add spending and savings categories, or use presets? Buttons **Use presets**
   (primary) and **Add categories**. Use presets closes the wizard.
3. A checkbox list of every preloaded category and subcategory. An **Advanced setup**
   button to the right opens Budget setup.

Still open (see prototype): where Back sits, what Done does at step 3, whether
"Add your own" (`0008` §8) stays, and how step 3 groups the list.

## 2. Budget setup: Add buttons

The four "Create in {Category}" field rows are replaced by **Add** buttons, one per
category. Selecting one shows that category's "Create in" fields above the button. A
polite announcement "Fields added above" is sent through the app's single live region.

## 3. Highlight

- Clicking an item name (purchase, item, category or subcategory) in Day, Week, Month
  or Annual opens a dialog showing that row and its children, with the same functions
  the table row has (`0007` §9, Edit menu below).
- Expand/collapse moves to the chevron button alone (`0008` §1 stays; the name no
  longer toggles).
- Prototype compares the current table with the highlight.

## 4. Edit menu (Day, Week, Month; not Annual)

- The row's "Actions" menu is renamed **Edit**.
- Items: **Description**, **Rename**, **Add/Subtract**, **Delete** (Day and Week only).
- Each opens a dialog, not an inline row form.
- Rename: if the new name belongs to a different category or subcategory, the item moves
  there.
- Description relates to the roadmap's "Optional description field below Amount" (v0.6);
  where it is stored is decided with that item.

## 5. Help dialog

Backup and upload are described in the help dialog (the "?" button), alongside the
onboarding questions. Upload itself is the v0.6 import item. How this merges with the
roadmap's "Combine Budget setup and help" is to be confirmed with the human.
