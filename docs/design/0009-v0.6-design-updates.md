# 0009 — v0.6 design updates

Human requests of 2026-11-04 from the v0.5 review. The wizard (§1) is decided
(`0010-onboarding-wizard-prototype.html`) and replaces the `0008` §8 single-dialog
questionnaire. The highlight (§3) is decided (`0011-highlight-prototype.html`).

## 1. Onboarding wizard

A dialog wizard with a progress bar (step X of 3).

1. How often do you get paid? (same options as `0008` §8)
2. Add spending and savings categories, or use presets? Buttons **Use presets**
   (primary) and **Add categories**. Use presets closes the wizard.
3. A checkbox list of every preloaded category and subcategory. An **Advanced setup**
   button to the right opens Budget setup.

Decided 2026-11-04 (from `0010`):
- Step 3: **Back** at the left, **Done** at the right, **Advanced setup** beside the list.
- The list is grouped by category and collapsible.
- No "Add your own" box in the wizard (it replaces the `0008` §8 box); adding names
  stays in Budget setup (Advanced setup).
- Step 2 does not list the presets. Its help text is "You can change presets later in
  Budget setup."
- Advanced setup closes the wizard.
- The wizard opens on first run (empty database), as the v0.5 questionnaire does.

## 2. Budget setup: Add buttons

The four "Create in {Category}" field rows are replaced by **Add** buttons, one per
category. Selecting one shows that category's "Create in" fields above the button. A
polite announcement "Fields added above" is sent through the app's single live region.

## 3. Highlight

- Clicking an item name (purchase, item, category or subcategory) in Day, Week, Month
  or Annual opens a dialog showing that row and its children, with the same functions
  the table row has (`0007` §9, Edit menu below).
- Expand/collapse moves to the chevron button alone (`0008` §1 stays; the name no
  longer toggles).
- The dialog shows the row **as it appears in the table being viewed** (decided
  2026-11-04): in Day, an item's purchases are its children and are listed; in Week,
  Month and Annual no purchases are listed because those tables do not show them.
- The name is a button with a **2px dotted underline** (decided 2026-11-04; a 1px
  dotted underline was rejected as unclear; `0011` shows other options that were
  not chosen).
- Hover styling is added to buttons and links across the app (roadmap item).
- Delete in the dialog asks for confirmation first and is hidden in Month and Annual
  (confirmed). A purchase row in Day also opens its own dialog (decided 2026-11-04);
  its functions are Add/Subtract (`0009` §4.1) and Delete. `0011` shows Week only and
  is not updated for Day.
- Prototype compares the current table with the highlight.

## 4. Edit menu (Day, Week, Month; not Annual)

- The row's "Actions" menu is renamed **Edit**.
- Items: **Description**, **Rename**, **Add/Subtract**, **Delete** (Day and Week only).
- Each opens a dialog, not an inline row form.
- Rename: if the new name belongs to a different category or subcategory, the item moves
  there, chosen with a Category select in the dialog (confirmed 2026-11-04). Rename is
  not offered for top-level categories (Income, Savings, Expenses).
- Description relates to the roadmap's "Optional description field below Amount" (v0.6);
  where it is stored is decided with that item.

### 4.1 Add/Subtract behavior (decided 2026-11-04)

- Amount fields accept typed expressions (`12.50+3`); see the roadmap item.
- **Day, category row:** a **New purchase** button opens the dialog and adds a new
  purchase to that category.
- **Day, purchase row:** Add/Subtract changes that purchase's amount (the result
  replaces the amount; the date stays).
- **Week and Month, item row:** Add/Subtract adds to or subtracts from the existing
  total. It is saved as a new positive or negative purchase (as `0007` §9.2 "Add
  value"), so the total moves by the amount entered.
- **Supersedes** `0007` §9.1 ("No editing of a purchase") and §9.4 (amount
  correction post v1.0) for the amount only. Correcting a purchase's date stays
  post v1.0.

## 5. Help dialog

Backup and upload are described in the help dialog (the "?" button), alongside the
onboarding questions. Upload itself is the v0.6 import item. How this merges with the
roadmap's "Combine Budget setup and help" is to be confirmed with the human.
